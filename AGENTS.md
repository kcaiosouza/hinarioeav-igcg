# GITHUB

Quando for realizar uma nova demanda seguir o seguinte passo-a-passo no git:

```
1. Crie uma branch com base na main (atualizado)
2. Realize a demanda
3. Commit as changes de forma granularizada, seguindo o padrão: tipo(contexto): descrição (ex: feat(ui): mudar cor do botão buscar)
4. Faça o push para o meu repositorio
5. Abra um PR para o repositorio Upstream
```
