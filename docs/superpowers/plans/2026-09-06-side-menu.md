# SideMenu (Drawer) & Dedicated Screens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a smooth animated side drawer menu accessible from the TopBar hamburger icon with navigation options (Hinário, Buscar, Favoritos), institutional footer credits, and dedicated Search and Favorites screens matching the dark forest theme.

**Architecture:** Custom animated overlay drawer using React Native's `Animated` and `Modal`/backdrop, seamlessly integrated into `app/index.tsx` and routing to `app/search.tsx` and `app/favorites.tsx`.

**Tech Stack:** React Native, Expo Router, TypeScript, Google Fonts (`Fraunces` & `Inter`), Native theme tokens.
